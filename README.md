# Marginalia

A list to keep track of what you read. It's a website, so it's pretty easy to use. The login pages and the sign-up pages do not allow you to create an account, so if you want to look at the dashboard and library pages you will need to type them manually into the URL. Creating books does not work, sadly (i know, it was kinda the whole point) but I should hopefully be able to fix that soon. The only book that is actually created is the demo book :(. So basically just click around and enjoy!
